# sm-scan 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 独立 Windows 桌面程序:三轨定期扫描空间代谢组学公开论文(Europe PMC 主题检索 / 32 刊 ISSN 订阅 / bioRxiv),SQLite 落库、Markdown 日报、PySide6 GUI、任务计划每日自动跑。

**Architecture:** 双入口——`sm_scan scan`(纯 CLI 引擎,任务计划调用)与 `sm_scan gui`(壳,只读写同一 SQLite、调用引擎函数)。三轨适配器隔离 API 差异,统一 `Paper` 记录入库,DOI 归一化主键去重,`matched_groups` 并集累加驱动日报三档+补漏分档。

**Tech Stack:** Python ≥3.10;依赖仅 `pyside6, requests, pytest`;SQLite(WAL,标准库);DPAPI 走 ctypes(crypt32.dll),零额外依赖。

**Spec:** `docs/superpowers/specs/2026-11-06-sm-scan-design.md`(v5.1,终审已通过)。执行者须同时读 spec——本计划只锁接口与测试,理由在 spec。

## Global Constraints(spec 逐字约束,所有任务隐含遵守)

- Python ≥3.10;依赖白名单:`pyside6, requests, pytest`(§18.2)
- 全部时间戳**本地时区** ISO;日报文件名 = 扫描开始时刻的本地日期(§5)
- 每次请求间隔 ≥1s、超时 30s、重试 2 次指数退避、User-Agent `sm-scan/0.1 (local research tool)`(§3.4)
- Europe PMC:`resultType=core`、POST 端点 `.../searchPOST`、字段 `TITLE_ABS`/`TITLE`、窗口 `FIRST_IDATE`、展示 `FIRST_PDATE`、显式检查 `resultList` 缺失与 `errCode`(§3.1)
- 所有检索短语一律双引号包裹(§4.3)
- Crossref:`mailto` 参数(polite pool)、`from-created-date`、`issued`→`pub_date`、12 个月保护、标题黑名单(§3.2)
- 分档计数用 `json_each(matched_groups)`,禁用 `LIKE`(§12)
- 零 API key;**不接入 OpenAlex**(§1)
- 数据路径绝对定位:开发态 = 仓库根下 `data/`、`reports/`;`sys.frozen` 时 = `sys.executable` 所目录(§2)
- git commit message 一律英文(用户项目规则)
- 日报数字口径:各分档之和 = 来源计数之和(§12,P2 修正)

## Review Focus(spec 隐含、任务测试之外最可能咬人的五类输入)

1. **pub_date 缺失/只有年月**(订阅回填的旧文常见):窗口比较与日报排序不得崩,按"日期未知"排尾。→ 测试加在 Task 7(窗口比较容缺)与 Task 8(日报渲染"日期未知")
2. **bioRxiv 返回非 JSON**(维护页):识别为该源失败,run 记 partial,不得抛异常栈。→ 测试加在 Task 11
3. **LLM 端点 401/坏 JSON**:单篇失败跳过计数、批量继续、不写缓存。→ 测试加在 Task 12
4. **DOI 混合大小写/分号拼接**(如 `"10.x/y; 10.x/yb"`):归一化取分号前第一段、转小写。→ 测试加在 Task 5
5. **断网三轨全挂**:run 记 failed、退出码 3、日报不生成,而非异常栈。→ 测试加在 Task 13
